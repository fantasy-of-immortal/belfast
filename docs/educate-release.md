# 旧版 TB 独立恢复分支（2026-10-07）

此分支只编译旧版 `270xx` 养成引擎。新版 `290xx/291xx` 引擎源码、新版 TB 管理 API 和相关测试已移除，不包含新版角色迁移 77。新版入口只做协议级拒绝，不加载档案，不切换到另一套状态实现。禁止把两个恢复分支直接合并为一个养成版本。

## 已恢复范围与限制

包含旧档兼容日期、基础日程和周结算、跳过、防重、任务快照、部分领奖、无折扣全池商店、固定出行/打工和部分目标选择限制。固定场景的已知收益使用旧版 JSON 存档事务，不写主港的金钱、油和物品。

未恢复的刷新/重置、手动追加任务进度/属性、好感升级、生成结局、普通事件占位入口明确失败，不保留原来的空成功。特殊事件仅保留真实配置中已查证的 type=2、result=0、无奖励展示；任何非零私有 result、折扣、奖励展示或其他类型均拒绝，也不会写完成标记。旧的养成奖励转写主港的 helper 已移除。

跨心情倍率、分数取整、随机池、折扣、完整好感/人格、特殊/心事奖励、结局等仍未完成。历史解锁结局可读取和选择，但不会通过占位入口生成新结局。这是部分恢复的审计版本，不是完整旧版恢复版。

## 验证

- 旧版养成包的完整测试通过；相关根包测试覆盖课程、商店、目标选择、已解锁展示选择和明确拒绝。
- 39 个新版禁用入口均通过无玩家、无数据库的协议测试。
- 角色隔离使用独立测试数据库中的外部角色哨兵，检查旧版事务不改动其 state、permanent、metadata、revision；不引入新版引擎作为测试依赖，也不等价于新版玩法验收。
- Windows 服务构建通过；全仓库测试仍有其他模块失败，不能宣称整仓库通过。

专项测试只允许实际数据库名以 `educate_recovery_test_` 开头的 DSN，使用随机隔离 schema；本仓库不附带玩家存档或提取的游戏配置。不得通过重置数据库、恢复备份或覆盖玩家存档切换版本。

本次拆分没有部署到玩家正在运行的服务，没有执行拆分后实机验收。当前分支与新版分支是分别构建、分别维护的版本。
