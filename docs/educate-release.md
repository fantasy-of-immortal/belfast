# 新版养成独立恢复分支（2026-10-07）

此分支只编译新版 `290xx/291xx` 养成引擎，按角色 ID 存储 state、permanent、metadata。旧版 `270xx` 引擎源码和它的测试已移除；注册表中的旧版入口只做协议级拒绝，不读取玩家档案。禁止把这个分支与旧版实现直接合并后作为一个养成版本发布。

## 已恢复范围与限制

包含角色独立存档、基础数值事务、基础课程、主事件展示链、部分天赋和固定生活体验的恢复代码。这是部分恢复的审计版本，并非整包玩法完成版。

旧评估、选择话题、获取/选择结局、重置、塔罗/词条、随机商店刷新、旧地图事件/会面、心事和决策占位入口已改为明确失败。它们不能绕过课程、清除待处理节点或提前完成阶段。尚未查证的条件、复杂课程链、额外奖励、完整天赋/塔罗、结局与无尽玩法仍未恢复。

托管 lifecycle 存档的管理 API PUT 只接受完全相同的快照作为 no-op；改变 state 或 permanent 返回 409，防止与 metadata 失配。独立角色迁移 CLI 保留。数据库升级只能使用正常迁移，不能通过恢复备份、清表或回退迁移来切换版本。

## 验证

- 新版养成包的完整测试通过，使用真实本地配置与独立测试数据库、随机隔离 schema。
- 审计测试覆盖占位入口无法绕过 MAP/PLAN 阶段，比较两个角色的 state、permanent、metadata、revision。
- 22 个旧版禁用入口均通过无玩家、无数据库的协议测试；27010 查询没有 result 字段，采用现有 10998 未支持命令回复，不能冒充空成功。
- 管理 API 的生命周期冲突和 no-op 保护已测试。
- Windows 服务构建通过；全仓库测试存在战斗、装备、岛屿、邮件等其他模块的失败，不能宣称整仓库通过。

运行测试必须显式提供独立测试 DSN；养成专项 DSN 的实际数据库名必须以 `educate_recovery_test_` 开头，不能仅在 URL 查询参数或密码中出现该字样。真实配置通过 `EDUCATE_RECOVERY_CONFIG` 指向本地 JSONL，本仓库不附带玩家数据和提取的游戏配置。

本次拆分没有部署到玩家正在运行的服务，也没有进行拆分后实机验收。此前实机证据属于混合工作区的具体切片，不应当作这个分支全玩法验收。
