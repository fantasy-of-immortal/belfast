## 4. 关闭语义合同需要的最小观测

所有数值是实验目标，不是伪造请求中的奖励参数。要从当时官方配置与可用会话选合法动作；无法恰好达到目标时，选最近可达边界并记录差异。

1. 比例/取整：对38100111收集小额心情正增量（如1、3、9）及其金钱奖励，区分30%向下取整、近似比例/除数、累计后取整；实际+30与两次+15也能区别逐次与合并取整。封顶时另外记录配置奖励和实际增量。
2. 跨动作计数：对确定性的38103211等，比较一次越过50门槛与两次小额合计越过门槛，随后再小额消耗，辨别跨动作累计与重复兑现。不要先用随机返还效果定性。
3. 回合/持有窗口：在自然回合边界前后观察同一已有效果，记录未满门槛余额是否带过；有合法效果升级/移除场景时再测计数是否继承。不会改数据库日期、补资源、重置或恢复进度。
4. 冲突参数：38102413的参数300与说明门槛10，必须以实际合法消耗后的百分比显示及掉落对照；不能选说明或参数之一当真值。
